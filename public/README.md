# public/

Drop the Coralux logo artwork in here as **`logo.svg`** (preferred) or
`logo.png`, and the app will use it automatically in the sidebar and on the
sign-in screen — no code change needed.

Until a file is present, the app draws its own wordmark
(`components/Logo.tsx`) in the brand colours.

A wide lockup works best: roughly 4:1, e.g. 800 × 200.
